# Phase 7.6 Security Test Matrix

| Scenario | Expected |
|---|---|
| No API key -> `/admin/tenants` | 401 |
| Tenant API key -> `/admin/tenants` | 403 |
| Platform owner -> `/admin/tenants` | 2xx/normal business validation |
| Tenant A -> Tenant A dashboard | Allowed only with dashboard tenant role |
| Tenant A -> Tenant B dashboard | 403 |
| Tenant owner -> platform dashboard | 403 |
| Platform owner -> platform dashboard | Allowed |
| Platform owner -> tenant dashboard | 403 by default |
| Tenant API key assigned PLATFORM_OWNER role | Still denied platform scope because principal is not platform |
| Platform admin assigns PLATFORM_OWNER to tenant API key | Rejected; only TENANT_* roles may be assigned |
| Tenant user -> tenant security dashboard | 403 |
| Tenant auditor -> tenant security dashboard | Allowed |
| Tenant billing admin -> tenant cost/dashboard operations | Allowed where explicitly permitted |
| Routing health -> tenant user | 403 |
| Metrics -> tenant user | 403 |

## Tenant isolation assertion

For every tenant-scoped endpoint:

`authenticatedTenantId == requestedTenantId`

must be true before tenant data is accessed.

Database schema routing remains a second independent enforcement boundary.
