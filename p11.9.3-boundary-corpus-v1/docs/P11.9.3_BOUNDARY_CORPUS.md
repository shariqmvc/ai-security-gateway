# P11.9.3 — Boundary Corpus

This phase targets the exact semantic confusions observed in P11.9.2.1.

Observed baseline:
- HARD_BENIGN -> DATA_EXFILTRATION
- HARD_BENIGN -> PROMPT_INJECTION
- INDIRECT_INJECTION -> SYSTEM_PROMPT_EXTRACTION
- RAG_POISONING -> PROMPT_INJECTION

The corpus therefore contains contrastive examples for those boundaries.

The boundary corpus is NOT inserted into the production semantic index.
It is evaluated against the existing P11.9.2 train reference index.

Interpretation:
- Top-1 expected label: direct category retrieval success.
- Top-1 contrast label: the exact confusion boundary was reproduced.
- Family appears Top-K: the semantic neighborhood is at least related to the
  intended boundary family.

This is diagnostic. It is not a production classifier benchmark.
