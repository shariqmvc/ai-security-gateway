# P11.9.4 — Semantic Evidence Scorer

## Objective

Convert the Top-K semantic neighborhood into label-level evidence rather
than using a single nearest neighbor as the classifier.

## Formula

For similarity `s`:

`weight = max(0, (s - floor) / (1 - floor))`

For rank `r`:

`contribution = weight * decay^(r-1)`

Contributions are summed by security label.

The resulting normalized values are evidence proportions within the retrieved
neighborhood. They are NOT probabilities and are not calibrated confidence.

## Default experiment

- Top-K: 5
- Similarity floor: 0.65
- Rank decay: 0.85

These values are deliberately experimental.

## Data isolation

The 530 P11.9.2 train examples remain the only indexed reference vectors.

The 120 test examples and 35 boundary examples are query-only.
