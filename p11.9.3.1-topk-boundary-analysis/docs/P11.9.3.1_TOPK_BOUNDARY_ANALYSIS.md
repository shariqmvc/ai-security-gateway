# P11.9.3.1 — Top-K Boundary Analysis

This experiment answers a specific question:

> When a boundary example is not classified correctly by its nearest vector,
> does the intended security category still exist in the Top-3 or Top-5
> semantic neighborhood?

The analysis uses the existing 530-example P11.9.2 train index.

The boundary corpus is query-only and is not inserted into PGVector.

## Taxonomy mapping

Some diagnostic concepts map to more than one operational security class:

- PROMPT_INJECTION -> PROMPT_INJECTION / INDIRECT_INJECTION
- INDIRECT_INJECTION -> INDIRECT_INJECTION / PROMPT_INJECTION
- RAG_POISONING -> RAG_POISONING / INDIRECT_INJECTION
- HARD_BENIGN -> BENIGN / HARD_BENIGN

This prevents synthetic family names from being incorrectly compared with
training family names.

## Decision

Do not use the output to change production thresholds.

The result determines whether a future semantic evidence scorer should use
Top-K aggregation rather than a single nearest neighbor.
